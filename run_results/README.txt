EXECUTED PROJECT RESULTS

These folders contain saved model metrics, predictions, exported notebook plots and
execution metadata for the nine main project notebooks. The final PowerPoint decks
are in updated_project_presentations/powerpoints/.

Current mock-project results are stored separately in mock/outputs/ and
mock/regression/outputs/. See the corresponding solution notebooks and READMEs
for their current fitting and evaluation workflows.

The recorded outputs describe the saved runs. Rerunning notebooks or changing the
model settings requires regenerating affected results, figures and presentation text.
